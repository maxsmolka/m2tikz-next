# Publication acceptance

Reusable scientific-export capabilities are accepted with redistributable,
independently generated fixtures. The public suite covers:

- line, marker, scatter, errorbar, legend, log-axis, and multiple-axes output;
- scalar images, colorbars, vector/hybrid image backends, and deterministic
  backend planning;
- axes-owned text and figure arrows with explicit ownership;
- grouped vertical bars and semantic boxplots;
- a narrow Cartesian 3-D contract with scalar Surface, Line3, Patch3, and
  ColorBar;
- publication profiles, figure sets, JSON replay, deterministic output, and
  caller lifecycle.

Fixtures use analytic curves, small deterministic matrices, synthetic
categories and quartiles, and generic Gaussian/trigonometric surfaces.
