# M6.3 modern tiled layout semantics

## Baseline and scope

Baseline: public/main a58028cf73e23b1104ecb0dd747a535714c4e0e8 after S1
was merged with all three required hosted checks green. Latest release remains
0.5.0. M6.3 adds one bounded, fixed, whole-figure MATLAB tiledlayout container;
it does not introduce native Octave tiledlayout support or general scene graphs.

## Architecture and support contract

The reader obtains GridSize, TileIndexing, Tile and TileSpan directly. It checks
cell bounds/overlap and decoration ownership, then orders axes physically
row-major with deterministic IDs. Runtime plotting rectangles are resolved with
callbacks deferred and preserved in handle-free IR. This path never calls
rectangle-based grid inference. Units are restored and lifecycle tests preserve
source geometry/data across repeated reads.

Existing LayoutIR grid cells gain optional tiled provenance for fixed
arrangement, source indexing, supported spacing/padding and resolved geometry.
Old grids remain unchanged. SharedLabelIR expresses title/X/Y ownership;
existing axes-owned legends and colorbars are reused. The renderer itself needs
no native API access or tiled-specific position guessing.

Supported: fixed grids, explicit/implicit tile creation, rectangular spans,
row-/column-major source indexing, empty cells, loose/compact/tight spacing
and padding, shared title/X/Y semantics, existing in-owner-tile decorations,
85/170 mm profiles and figure sets. Native graphic-family limitations still
apply inside each axes.

Explicit exclusions: flow/vertical/horizontal arrangements, nested/multiple
or partial-figure layouts, mixed manual/tiled ownership, hidden layouts,
invalid/overlapping cells, subtitles/custom shared-label rotations, outer or
multi-tile decorations and zero spacing. E056/E057/E058 diagnose these classes
before public output. Details are in docs/TILED_LAYOUTS.md and ADR-0022.

## Evidence-driven profile correction

Initial compilation alone passed but visual review found two defects: shared
Y text collided with ticks at 85 mm, and zero tile spacing collided with tick
labels. The first outer-gutter correction passed its initial visual subset, but
a further pre-merge probe with simultaneous local/shared labels still collided.
The final profile reserves outer and per-cell physical text gutters, places
explicit grid cells/spans, and transforms colorbars relative to their owners.
Cells and scientific data remain unchanged. Shared labels use physical-margin anchors. Untiled profiles
are unchanged. Figure-space annotations fail this optional transform because
their relationship to moved axes cannot safely be inferred.

Zero spacing is explicitly unsupported rather than hiding labels, changing
data, or silently inventing gaps. Tight (nonzero) spacing passes the reviewed
fixture. This bounded contract is not a general font-metric solver: long labels
or very dense grids still require suitable figure size and visual review.
