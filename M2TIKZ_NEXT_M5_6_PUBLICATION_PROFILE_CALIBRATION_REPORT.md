# M5.6 publication profile calibration

M5.6 ratified the existing 85 mm and 170 mm profile widths and 10/9/8 pt text
hierarchy. Calibration is presentation-only and preserves scientific content,
styles, annotations, legend/colorbar geometry, and relative layout.

The public acceptance suite now uses only independent synthetic line, legend,
image/colorbar, annotation, multiple-axes, grouped-bar, boxplot, and narrow 3-D
fixtures. Exact compiled width, JSON/TeX determinism, figure-set determinism,
and caller lifecycle remain tested.
